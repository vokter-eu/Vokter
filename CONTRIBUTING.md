# Contribuir a Vokter

Gracias por estar aquí. Vokter lo construyen personas, no corporaciones.

## Cómo ayudar hoy (Fase 0)

- **Prueba el arranque rápido** del README en tu máquina y abre un issue con lo que falle o confunda. Cada sistema operativo y cada GB de RAM cuentan.
- **Discute la arquitectura**: la hoja de ruta vive en las Discussions. Opiniones técnicas fundadas valen oro ahora que todo es maleable.
- **Traduce**: el proyecto nace en español; el inglés y otras lenguas europeas son bienvenidas.
- **Difunde**: una estrella o un mensaje a quien le importe la privacidad ayuda más de lo que parece.

## Reglas del juego

1. Sé amable. Aquí cabe gente de todos los niveles.
2. Toda contribución de código se publica bajo AGPL-3.0.
3. **Línea roja innegociable**: ningún PR que envíe datos del usuario a servicios de terceros sin consentimiento explícito será aceptado, por útil que sea.

## Proceso

Issues para bugs y propuestas concretas; Discussions para ideas abiertas; PRs pequeños y enfocados mejor que gigantes. El mantenedor responde en español e inglés.
